# Find AR

나는 회사의 대표야. 지금 모바일 앱을 하나 만들려고해. 모바일앱은 구인자와 구직자를 연결하는 매칭플랫폼이고, 구직자의 주요 사용자는 외국인 일용직 구직자가 70%, 내국인 구직자가 30% 정도라고 보면 되고, 구인자의 주요 사용자는 호텔, 모텔, 리조트, 식당, 병원, 요양원에서 인력관리를 하는 소장 같은 관리자가와 인사팀 구인관리자가 될꺼야.
구조는 다음과 같아.
1. 크게 세개의 구성 (구인자, 구직자, 앱관리자)
2. 구인자는 구인정보를 입력
3. 구직자는 모바일앱 가입 시 본인의 간단한 신분(외국인, 내국인)과 경력(5회 미만, 5회 이상)입력, 한국어 사용 가능 여부 입력. 비자상태(학생, 구직, 거주, 기타) 입력
4. 구인자는 일할 곳의 장소정보(사진, 일할곳 이름, 위치)와 일당 그리고 급여지급일을 입력하고 출근 시 필요한 것들 기입할 수 있어야하고, 가입시 기본정보 입력에 있는 정보를 사용할 수도 있어야해.
4. 구인자와 구직자를 연결하는 플랫폼이지만, 구직자는 무료로 사용할 것이고, 구인자는 크레딧을 구매해서 사용해야해.
5. 구직자가 구인자가 올려놓은 정보를 확인해서 일하고 싶다고 구인자에게 요청하면, 구인자는 요청을 수락하는 형태로 연결되는 것이고, 수락(승인)을 하면 구직자에게 출근관련 세부사항을 모바일로 전달받는 형태로 하고 싶어.
6. 구인자가 구직자의 요청을 승인하면, 구직자에 대한 정보를 받게 되고 모바일상에서 연락을 할 수 있게 되어서 서로 연결해주는 시스탬이야. 여기서 승인을 하려면 크래딧이 있어야 승인을 할 수 있는 시스탬이지.
7. 크래딧은 구인자가 모바일앱에 가입을 하면 기본 2크레딧은 제공하지만, 추가로 크레딧이 필요하면 그레딧을 구매해야해. 구매 단위는 20, 50, 100 단위로 하려해. 1크레딧 가격은 1,000원으로 할꺼야.
8. 모바일앱에 가입할 때 구인자는 간단한 본인의 회사정보(회사명, 위치, 담당자이름, 연락처 정도만 입력. 구인 정보는 별도의 페이지에서 입력할 수 있게 할꺼야. 
9. 구인정보는 호텔, 모텔, 리조트, 식당, 병원, 요양원 으로 구분하면 되고, 호텔/모텔/리조트는 객실청소와 기물 (설겆이)청소, 식당은 설겆이와 홀써빙, 병원/요양원은 간병(Care)로 나뉘서 진행 되어야 해.
10. 호텔/모텔/리조트로 구인을 입력하는 경우 객실청소로 구인하는 경우 일일청소 객실수를 반드시 입력하도록 해야 하고, 다른 경우는 필수입력은 아니야.
11.  모든 구인정보에는 담당자의 연락처를 입력하도록 해야하지만, 기본정보에 입력한 연락처를 사용할 수 있거나, 개별담당자의 연락처를 입력할 수 있어야해. 이연락처는 구직자에게는 비공개가 원칙이야.
12. 구인자가 입력한 구인정보에 대하여 제한 수는 20개까지만 올릴 수 있게 제한해야해.
13. 구직자는 가입할 때, 추전인 정보를 넣을 수 있는 공간을 넣어줘. 이부분은 모바일 관리자페이지에서 구직자 추천인을 개별적으로 관리하려고 해. 추천인이 몇명을 가입시켰는지 확인할 수 있어야해.
13. 구직자는 구인정보를 볼 수 있는 페이지가 첫 화면으로 나와야 하고, 상단에 지역별로 검색할 수 있는 기능이 있어야해. 위치기반으로 찾기 선택을 하는 것도 가능해야해.
14. 추천 구인정보 페이지가 있어야 하는데, 추천 구인정보는 크게 세가지로 나뉘어. 상단은 구인자가 크레딧을 사용해서 배너형태로 보여주는 곳 (최대 12개), 다음은 랜덤으로 구인정보를 배너형태(최대 20)로 보여주는 곳으로 배너들은 2개씩 나열되는 형태가 좋아. 그 다음은 별도의 광고배너가 나오는데. 이건 1개씩 3개정도로 3줄로 나오도록 하고 싶어.
15. 추천 구인정보에 구인자가 배너로 광고를 하고 싶으면, 크레딧을 써야하는데 광고 기간은 2일(10 크레딧), 5일(20 크레딧), 10(25 크레딧)을 사용해야해. 크레딧 사용이 없으면 무료 랜덤 배너로 보여지는 형태야. 별도의 광고배너는 관리자에게 별도 연락으로 하는 것으로 설정해줘.
16. 구인자는 구인정보 입력 시, 필요한 일자를 선택하고, 그 곳에서 정보를 입력해야해.
17. 구인자와 구직자가 매칭 연결이 승인으로 완료되면, 승인 된 기록이 저장되어야 해. 저장된 기록은 구인자와 구직자 모두 일단위/주단위/월단위로 승인기록을 볼 수있어야해.
18. 모바일 관리자는 별도의 페이지가 있어야하는데, 모바일이 아닌 PC에서만 관리하도록 웹페이지 형태로 만들어야해. 관리할 사항들은 가입자들의 정보를 보고 관리할 수 있어야 하고, 크레딧 정보를 확인하고 구인자에게 크레딧을 무상으로 제공할 수 있는 기능이 있어야해. 그리고 추천페이지 하단에 나오는 광고 배너를 관리할 수 있는 기능이 있어야 하는데 기간 설정이 가능해야해.

참고할 수 있는 모바일앱은 '알바프리', '동네알바' 같은 앱이 있어.
