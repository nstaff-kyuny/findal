# Google Play Console 다음 단계 계획

## 1. 앱 만들기
1. Play Console 메인에서 **"앱 만들기"** 버튼 클릭
2. 앱 이름: **Find AR**
3. 기본 언어: **한국어(ko-KR)** 또는 **영어(en-US)** 선택
   - 주 사용자가 한국어이므로 한국어를 기본값으로 두는 것을 권장
4. 앱 유형: **앱** 선택
5. 유료/무료: **무료** 선택

## 2. 앱 정보 설정
1. **앱 접근 권한** → "모든 기능을 무료로 사용할 수 있습니다" 선택
2. **광고** → 광고가 없으면 "아니요" 선택
3. **콘텐츠 등급** → 설문 완료 (일자리 매칭 앱에 맞게 응답)
4. **대상 연령층** → 18세 이상 또는 전체 연령대 선택
5. **데이터 보안** → 수집하는 데이터 항목 입력
   - 위치 정보, 연락처, 이메일, 전화번호, 기기 ID 등
   - 수집 목적 및 공유 여부 기재
6. **개인정보처리방침** URL 입력
   - `https://findar.nstaff.co.kr/privacy` 또는 회사 정책 페이지

## 3. 스토어 등록정보(Store Listing) 작성
1. **앱 세부정보**
   - 간단한 설명: 80자 이내
   - 자세한 설명: 4000자 이내
2. **그래픽 에셋**
   - 앱 아이콘: 512×512 PNG
   - 기능 그래픽: 1024×500 PNG
   - 스크린샷: 휴대폰 2~8장, 7인치/10인치 태블릿 선택사항
3. **연락처 정보**
   - 이메일: `nstaff@nstaff.co.kr`
   - 웹사이트: `https://findar.nstaff.co.kr`

## 4. 앱 빌드 업로드
1. Android Studio에서 **Release AAB** 생성
   - `Build → Generate Signed Bundle / APK → Android App Bundle`
   - 키스토어는 안전한 위치에 백업
2. Play Console → **생산용** 트랙 → **국가/지역** 설정
3. **새 버전 만들기** → AAB 파일 업로드
4. 출시 이름과 버전 정보 입력

## 5. 검토 및 출시
1. **대시보드**에서 완료해야 할 항목 모두 체크
2. **정책 → 콘텐츠 등급, 데이터 보안, 개인정보처리방침** 확인
3. **출시 검토 요청** 클릭
4. Google 검토(보통 1~7일) 완료 후 프로덕션 출시

## 6. 병행해야 할 사항
- iOS App Store Connect에서도 동일한 시점에 **TestFlight / 프로덕션 심사** 진행
- 앱 아이콘, 기능 그래픽, 스크린샷 이미지를 미리 준비
- 개인정보처리방침 페이지가 실제 웹사이트에 존재하는지 확인
