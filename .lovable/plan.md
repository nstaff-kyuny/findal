# MacInCloud 키보드 입력 복구 계획

1. MacInCloud 원격 화면 상단 또는 측면 메뉴에서 **Request Control / Take Control / Control**을 눌러 보기 전용 상태를 해제합니다.
2. 브라우저가 키보드·클립보드 사용 권한을 묻는 경우 **허용**을 선택합니다.
3. Mac 화면 안의 터미널 창을 한 번 클릭하고, 영문 `a`를 눌러 키보드 입력이 전달되는지 확인합니다.
4. 입력되지 않으면 원격 연결을 종료한 뒤 MacInCloud 대시보드에서 **Connect Now**로 다시 접속하고 제어를 다시 요청합니다.
5. 키보드가 작동하면 `Password:` 상태에서 MacInCloud 로그인 비밀번호를 입력하고 **Enter**를 누릅니다. 비밀번호 문자는 화면에 표시되지 않는 것이 정상입니다.
6. Windows 키보드는 **Windows 키 = Command(⌘)**, **Alt = Option(⌥)**으로 사용합니다.
7. 비밀번호 인증이 완료되면 Xcode 초기 설정 명령과 프로젝트 열기 단계로 계속 진행합니다.
