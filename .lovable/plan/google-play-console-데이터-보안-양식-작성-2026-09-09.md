# Google Play Console 데이터 보안 양식 작성

## 현재 단계
스크린샷은 **데이터 유형** 선택 화면입니다. Find AR 개인정보처리방침에 따라 아래 항목을 체크합니다.

## 3단계 — 선택할 데이터 유형

- **위치**
  - 대략적인 위치 (선호 지역/지역 매칭용) — 필수
  - 정확한 위치 (GPS) — 앱이 실시간 GPS를 수집하는 경우에만 체크
- **개인 정보**
  - 이름
  - 이메일 주소
  - 전화번호
  - 기타 개인 정보 (국적, 비자, 경력, 회사명, 담당자 정보 등)
- **재무 정보** — 앱 내에서 결제/크레딧 기록을 보관한다면
  - 구매 기록
- **기기 또는 기타 ID**
  - 기기 또는 기타 ID (푸시 알림 토큰, 접속 기기정보, Firebase 식별값)

선택하지 않아도 되는 항목: 사진·동영상, 오디오, 파일·문서, 캘린더, 연락처, 메시지, 건강·피트니스, 웹 검색 등은 현재 기능에 없습니다.

## 4단계 — 데이터 취급 및 처리 (다음 화면)

각 데이터 유형별로 아래 기준으로 응답합니다.

| 항목 | 응답 |
| --- | --- |
| 수집/공유 여부 | 예 (앱 기능 제공에 필요) |
| 처리 목적 | 앱 기능(매칭, 알림, 결제), 계정 인증, 고객 지원, 부정 이용 방지 |
| 데이터 공유 | 매칭 상대방에게 연락처 공개(승인 시) 외에는 제3자 미공유. 결제는 토스페이먼츠가 별도 처리 |
| 전송 중 암호화 | 예 (HTTPS/TLS) |
| 삭제 요청 | 사용자는 설정 → 회원 탈퇴 또는 `/delete-account` 안내 페이지를 통해 삭제 요청 가능 |

## 5단계 — 미리보기 및 저장

- 누락된 항목이 없는지 확인
- **저장** 클릭

## 병행 확인사항

- 개인정보처리방침 URL: `https://findar.nstaff.co.kr/privacy`
- 계정 삭제 안내 URL: `https://findar.nstaff.co.kr/delete-account`
- 앱이 정확한 GPS를 수집하지 않는다면 **정확한 위치**는 체크하지 않습니다.
