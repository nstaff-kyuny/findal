# 구글 플레이 검색 노출 개선: 수정할 곳과 넣을 문구

Google Play에는 App Store 같은 **별도 '키워드' 입력란이 없습니다.** 검색은 **앱 이름, 간단한 설명, 자세한 설명**의 글자를 기준으로 이루어집니다. 그래서 이 세 곳에 검색어가 자연스럽게 들어가 있어야 합니다.

## 수정 위치
Play Console → Find AR 선택 → 왼쪽 메뉴 **성장 (또는 '사용자 늘리기') → 스토어 등록정보 → 기본 스토어 등록정보** → 수정 → 저장 → **게시 개요에서 '검토를 위해 변경사항 제출'**

- 언어가 **한국어(ko-KR)**인지 확인하세요. 영어로만 되어 있으면 한국어 번역을 추가해야 합니다.

## 1. 앱 이름 (최대 30자) — 가장 효과가 큼
지금은 `Find AR`만 있어서 'find ar' 검색에만 나옵니다. 추천 문구:
- `파인달 Find AR - 호텔알바·일용직` (가장 추천)
- `Find AR 파인달: 호텔·모텔 청소 알바`

## 2. 간단한 설명 (최대 80자)
`호텔알바·모텔청소·리조트알바·일용직 단기 일자리를 내 주변에서 찾고 바로 지원하세요.`

## 3. 자세한 설명 (최대 4000자) — 첫 3~4줄이 중요
```text
파인달(Find AR)은 호텔·모텔·리조트 현장과 일할 사람을 이어주는 단기 일자리 앱입니다.

■ 이런 일자리를 찾을 수 있어요
- 호텔알바, 호텔청소, 객실정비(하우스키핑)
- 모텔청소, 리조트알바, 펜션 청소
- 일용직·단기 알바, 당일 근무

■ 구직자
- 내 주변 일자리 지도와 목록으로 확인
- AI 채팅으로 맞는 일자리 추천
- 간편 지원과 근무 기록, 근무 확인서 PDF 발급

■ 구인자(호텔·숙박업체)
- 필요한 날짜·인원으로 공고 등록
- 지원자 확인과 근무 승인 관리

운영: 주식회사 엔스태프(N STAFF)
```
위 기능 목록은 앱에 있는 기능 기준입니다. 실제와 다른 항목은 빼 주세요.

## 지켜야 할 규칙 (어기면 심사 거절)
- 같은 단어를 억지로 반복하거나, 설명 끝에 검색어만 나열하지 마세요.
- 다른 앱 이름(급구, 일다오 등)은 넣지 마세요.
- '1위', '최고', '무료' 같은 근거 없는 표현은 피하세요.
- 앱 이름에 이모지나 특수기호를 과하게 쓰지 마세요.

## 추가로 효과 있는 것
- **대표 이미지·스크린샷**에 '호텔알바', '객실청소' 같은 문구를 넣으세요(예: 앞서 만든 광고 이미지).
- **App Store에도 맞춰서** 앱 이름/부제목을 `파인달 Find AR` / `호텔 모텔 단기 알바 구인구직`으로 바꾸면 양쪽이 일관됩니다.
- 리뷰와 설치 수가 늘수록 순위가 올라갑니다. 기존 근무자·호텔 고객에게 설치·리뷰를 부탁하세요.

## 기대치
- 심사 통과 후 검색 반영까지 보통 **며칠~2주**가 걸립니다.
- '파인달', '호텔청소', '모텔청소'처럼 경쟁이 적은 단어는 비교적 빨리 노출될 수 있습니다.
- '일용직', '호텔알바'는 큰 앱이 많아 상위 노출을 약속할 수 없습니다.

## 앱에서 할 작업 (승인 시)
- 프로젝트의 스토어 등록 문서를 위 문구로 업데이트해서 복사·붙여넣기용으로 정리합니다. 앱 자체는 다시 빌드하거나 업로드할 필요가 없습니다.
