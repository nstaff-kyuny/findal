# Google Play 심사용 로그인 계정 준비

## 이 화면에서 선택할 것

- **"예"** 선택 (현재 선택된 상태가 맞습니다) — 앱은 로그인이 필요하므로 그대로 둡니다.
- **세부정보 추가** 버튼을 눌러 심사팀이 쓸 계정을 2개 등록합니다.

## 만들 계정

| 구분 | 이메일 | 비밀번호 |
| --- | --- | --- |
| 구직자 | reviewer.seeker@nstaff.co.kr | 심사 전용 임시 비밀번호 |
| 구인자 | reviewer.employer@nstaff.co.kr | 심사 전용 임시 비밀번호 |

- 이메일 인증 없이 바로 로그인되도록 확인 처리된 상태로 만듭니다.
- 구직자 계정에는 이름·연락처가 채워진 기본 프로필, 구인자 계정에는 회사 정보와 심사 확인용 크레딧을 넣어 두어 심사팀이 공고 등록·결제 화면까지 볼 수 있게 합니다.
- 비밀번호는 채팅에 남기지 않고, 만든 뒤 안전하게 전달할 방식(원하시는 값 지정 또는 제가 생성한 값 안내)을 정합니다.

## Play Console 입력 방법

1. **세부정보 추가** → 이름 `구직자 심사 계정`, 사용자 이름/이메일과 비밀번호 입력
2. 다시 **세부정보 추가** → 이름 `구인자 심사 계정`, 동일하게 입력
3. 안내 메모란(있는 경우)에 "회원가입 시 구직자/구인자 유형을 선택합니다. 위 두 계정으로 각각의 화면을 확인할 수 있습니다." 기재
4. **저장** 클릭

## 기술 세부사항

- 마이그레이션으로 `auth.users`가 아니라 관리자 API 경로를 사용해 두 사용자를 생성하고, `public.user_roles`에 각각 `seeker`, `employer` 역할을 삽입합니다.
- 프로필/회사 정보 테이블에 대응 행을 함께 넣어 로그인 직후 온보딩 막힘 없이 화면이 뜨도록 합니다.
- 기존 회원가입 흐름·정책은 변경하지 않습니다.
